## Введение
Модуль предоставляет MCP-сервер с набором специализированных инструментов для упрощения AI-разработки, а так же необходимый контекст и структуру для генерации качественного кода под экосистему 1С-Битрикс.

## Требования
- PHP >=8.2
- 1С-Битрикс >= 24.0.0

## Установка
1. Скопируйте папку модуля `ade.boostrix` в директорию `/local/modules/` вашего проекта 1С-Битрикс.
2. В административной панели 1С-Битрикс перейдите в раздел "Marketplace" → "Установленные решения".
3. Найдите модуль "ade.boostrix" и выполните установку, следуя инструкциям мастера.
4. После установки убедитесь, что модуль активен.

## Регистрация MCP-сервера
Для регистрации сервера в выбранном вами редакторе используйте следующие данные:

Через docker:
```json
{
    "mcpServers": {
        "boostrix": {
            "command": "docker",
            "args": [
              "exec", "-i",
              "#Имя контейнера#",
              "php", "#Путь до корня проекта#/local/ade.boostrix/tools/server.php"
            ]
        }
    }
}
```

Без docker, php работает локально:
```json
{
    "mcpServers": {
        "boostrix": {
            "command": "php",
            "args": ["#Путь в системе до корня проекта#/local/ade.boostrix/tools/server.php"]
        }
    }
}
```

## Доступные MCP-инструменты
| Название                    | Описание                                       |
|-----------------------------|------------------------------------------------|
| Информация о проекте        | Читает версию PHP и главного модуля 1С-Битрикс |
| Список консольных команд    | Читает доступные консольные команды            |
| Список роутов               | Читает роуты проекта                           |
